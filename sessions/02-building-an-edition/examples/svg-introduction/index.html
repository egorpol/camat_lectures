What is SVG?

A picture described with text. Your browser reads the description and draws it.

SVG means Scalable Vector Graphics. Lines, shapes and their positions describe the picture. You only need to change one value to see the connection.

Three words we will use
A tag, such as <circle>, names an element. An attribute, such as fill="black", gives it a property. A group, <g>…</g>, keeps several elements together.

  


  

    
2 · Why “scalable”?

    
Enlarge the same note symbol

    
The PNG stores a grid of 32 × 32 coloured squares (pixels). The SVG stores an oval and a line. Both were made from this same simple drawing, not from a historical scan.

    

      
      
    

    

      
PNG · a fixed pixel grid

      
SVG · shapes drawn at this size

    

    
The checked option deliberately reveals the PNG's squares. Uncheck it to see the browser's usual smoothing. Enlarging the PNG cannot recover detail absent from its 32 × 32 source.

    
Does saving a scan as SVG make it sharper?
An SVG can contain a PNG through an <image> element. That still contains the same fixed pixel image. A PDF can also contain either scanned images or vector drawings. The file extension alone does not tell us which is inside.

  


  

    
3 · Back to our edition

    
One note, two descriptions, the same address

    
Here is Schumann's pickup. Our starting MEI records the note as C3, an eighth note. Verovio draws it as SVG and keeps its address, d1e60. Click the note to connect the drawing with that address.

    

      
      
      
      
    

    

    

    

      
MEI · the musical information
pname="c": pitch letter C. oct="3": octave 3. dur="8": eighth note.

      
SVG · the drawing and its address
g groups the drawn parts; id gives an address. The shapes inside draw the notehead, stem and flag.

    

    

    
The C3 and F3 examples were engraved in advance with Verovio 6.3. The selector switches between those prepared renderings. F3 is an artificial teaching change, not a proposed correction to Schumann.

    
Why can an LLM use this?
A model can inspect the score image and use SVG's IDs to name the exact MEI target. Extra data-* attributes copy values from the current encoding; they do not verify them against the scan. Our editorial exercise gives the model the scan, current engraving and MEI together.

  


  

    
Three questions before we continue

    
  1. If we colour a note blue, have we changed its pitch?
  2. Which file records C3 and its duration: MEI or an ordinary SVG drawing?
  3. When the engraving differs from the witness, which one do we consult for the reading?

    
Suggested answers
Colour changes appearance. MEI carries the musical encoding; SVG may repeat selected MEI values as added metadata. The printed witness supplies the source reading, and we check how that reading is encoded and rendered.
