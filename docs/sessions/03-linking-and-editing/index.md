# 3. Building an edition: linking and editing

Session 3 (double session, 2 × 90 minutes).

We continue the edition of Schumann's *Fröhlicher Landmann* from [session 2](../02-building-an-edition/index.md). Today every bar gets a link to its place on the page image, and we make three corrections to the encoding, comparing each with the print: two by hand, one with the help of Copilot. Then we check each other's work.

!!! tip "Before the session"
    Your laptop should be set up as in session 2: the check in `02_pdf_preparation.ipynb` prints `CAMAT: 0.2.8`, and the notebook has run to the end once. If not, follow the [setup page](../../setup-laptop.md) and run the notebook before class. Everything today happens in the same folder, `02-building-an-edition`, so that the notebooks find your project `schumann_edition_work`.

**What we will do**

| | |
|---|---|
| Block 1 | Link each bar to its region on the page image. What SVG is: how the score in the browser is drawn. Edit the MEI in VS Code and watch the score change. First edit, by hand: the opening tempo and dynamic. |
| Block 2 | Second edit, with Copilot: the opening slurs, checked against the scan. Third edit: a note in the file that explains a decision. The same file in mei-friend, an MEI editor in the browser. Peer review: a partner checks your edits against the print. |

The full page with the steps and the notebooks follows before the session.
